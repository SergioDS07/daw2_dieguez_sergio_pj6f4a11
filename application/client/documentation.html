Documentation

EuroCulture Order Manager is an e-commerce application used by the sales team of a European chain of cultural shops (museum and theatre tickets, books and art merchandise) to register and consult customer orders.

Operations menu

Create a new order

Fill in the order code, the customer's full name, address, email and phone. Tick the products the customer wants and enter a quantity for each one. Press "Send order": the server calculates the price including 21% VAT, stores the order and shows you the total.

View orders

All orders: shows a table with every stored order.
One order: type an order code and the application shows that order in a table. If the code does not exist, an error is shown.

Access requires logging in with a valid user name and password.
